# 🕒 Analog Clock using JavaScript

A simple and responsive **Analog Clock** built using **HTML, CSS, and JavaScript**.  
This project displays real-time hours, minutes, and seconds using dynamic rotation of clock hands.

---

## 🚀 Features
- Real-time clock updates
- Smooth movement of second, minute, and hour hands
- Clean and minimal UI
- Responsive design

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

---

## 🧠 What I Learned
- JavaScript `Date()` object
- Using `setInterval()` for real-time updates
- DOM manipulation
- CSS transforms and rotations
